# Dockgeek translations

Translations included in Dockgeek v2 are English (`en`), Simplified Chinese (`zh-CN`), and Russian (`ru`). To contribute, edit the corresponding files in `frontend/src/lang/` and open a pull request at [one-zero-eight/dockgeek](https://github.com/one-zero-eight/dockgeek/pulls). Add new English UI strings to `en.json` first.
